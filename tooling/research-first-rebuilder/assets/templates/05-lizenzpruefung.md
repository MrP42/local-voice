## Geprüfte Fallen

- [ ] Stub-LICENSE ohne Volltext / ohne Rechteinhaber
- [ ] „Apache-2.0 mit Zusatzbedingungen"
- [ ] Open-Core-Unterverzeichnis (`enterprise/`, `ee/`, `pro/`)
- [ ] Name / Logo / Icons von der Code-Lizenz ausgenommen
- [ ] Dual License (getroffene Wahl dokumentiert)
- [ ] Lizenzwechsel in der Historie
- [ ] Transitive Abhängigkeiten
- [ ] Modell- und Datensatzlizenzen (getrennt von der Code-Lizenz)
- [ ] Vendored Code (`third_party/`, `vendor/`)
